# 外部资源合规清单

竞赛规则要求获奖方案**披露所有使用的外部数据与模型**，并确认使用权合规。
本清单在引入每一项外部资源时**立即登记**；许可证字段取自 Kaggle API（`datasets/view`），非转述。

**两条影响许可证选择的硬约束**：
1. 竞赛数据为 **CC BY-NC 4.0**（非商用）；获奖方案将被开源。
2. Kaggle Notebook 评分时**断网**，所有依赖与权重必须预先打包为 Kaggle Dataset。
